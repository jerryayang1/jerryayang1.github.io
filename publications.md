### Publication title

```bibtex
@article{key,
  author  = {Author, First and Coauthor, Name},
  title   = {Publication title},
  journal = {Journal or Conference Name},
  year    = {YYYY},
  volume  = {volume},
  pages   = {start--end}
}
```

Inline LaTeX such as $\mathrm{SiO_2}$ and $10^3$ will render when MathJax is
enabled. Add additional entries using the same structure.
